# Feedmcp

`feedmcp` is a Model Context Protocol (MCP) server designed to supercharge Large Language Models (LLMs) with your offline documentation. 

It natively reads `.zstd` compressed markdown archives (generated by tools like [`feedai`](https://github.com/akhenakh/feedai)), splits them into semantic chunks, and indexes them into a high-performance SQLite FTS5 database. It then exposes this database to AI agents (like Claude Desktop, Cursor, or custom clients) so they can dynamically search and read your docs.

## Features

- **Direct ZSTD Support**: Reads massively compressed `.md.zstd` archives without needing manual extraction.
- **Smart Chunking**: Uses LangChainGo to intelligently split long markdown files by headers and size, ensuring the LLM gets perfect context windows.
- **Fast BM25 Search**: Powered by SQLite FTS5. Ranks search results prioritizing filenames and markdown headers.
- **Multi-Transport**: Runs over `stdio` (for local desktop apps), `sse` (Classic Server-Sent Events), or `streamable` (Streamable HTTP for modern web clients).
- **CORS Enabled**: Out-of-the-box support for web-based MCP inspectors and browser TUI clients.

## Installation & Build

```bash
# Clone your repository
git clone https://github.com/akhenakh/feedmcp.git
cd feedmcp

# Build with the FTS5 tags enabled (REQUIRED)
go build -tags sqlite_fts5 -o feedmcp .
```

## Quick Start Workflow

### Ingest Documentation

Point `feedmcp` to a directory containing your `.zstd` archives. It will create a local SQLite index (default: `docs.sqlite`).

```bash
./feedmcp ingest ~/dev/feedai/docs/
```
*You can customize the database location by adding `--db /path/to/myindex.sqlite` before the `ingest` command.*

### Start the Server

**For Claude Desktop or CLI Agents (Stdio):**
```bash
./feedmcp serve --db docs.sqlite --transport stdio
```

**For Web Clients, Cursor, or Remote Agents (Streamable HTTP / SSE):**
```bash
# Modern Streamable HTTP (available at http://localhost:8080/mcp)
./feedmcp serve --db docs.sqlite --transport streamable --port 8080

# Classic SSE (available at http://localhost:8080/sse)
./feedmcp serve --db docs.sqlite --transport sse --port 8080
```


## Client Integration Examples

### Opencode

Edit `~/.config/opencode/opencode.json`:

```yaml
  "mcp": {
    "feedmcp": {
      "type": "local",
      "command": ["feedmcp", "serve", "--db", "/home/youruser/dev/feedmcp/docs.sqlite", "--transport", "stdio"],
    },
```
